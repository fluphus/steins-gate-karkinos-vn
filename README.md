# STEINS;GATE 不可侵领域的 Karkinos

三章 Web 移植版。首页点「新游戏」进入剧情模式。要自己解谜，可在新游戏开始前从设置选择解谜模式。浏览器会保存当前进度，回到同一站点可点「继续游戏」。

## 部署到 GitHub Pages

1. 解压本包，在本地 Git 仓库中将文件放到发布分支的根目录。根目录应直接包含 `index.html`、`.nojekyll` 和 `assets/`。
2. 用 Git 提交并推送解压后的全部文件。附录视频约 65 MiB，请使用 Git 客户端推送。
3. 在仓库的 Settings → Pages，选择 Deploy from a branch，选定该分支和 /(root)，保存。
4. 部署完成后，打开 Pages 显示的站点地址。仓库项目站点一般位于 `https://用户名.github.io/仓库名/`。

游戏、配音、影片与解谜资料均随包提供。浏览器存档按站点保存，本地工作版的进度不会自动复制到 Pages 站点。

网页使用导出的立绘、纹理与解谜几何。
